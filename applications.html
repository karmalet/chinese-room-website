《北京大学现代汉语实词句法语义功能信息词典》 介绍 Introduction： 《北京大学现代汉语实词句法语义功能信息词典》（简称《实词信息词典》）是一个电子化的语言知识资源，知识内容主要是现代汉语常用形容词、动词和名词的句法功能、语义角色及其组配方式、主要句型及其典型例句；并且，配备完善与方便的检索系统。《实词信息词典》主要是为汉语自动语义分析和文本生成、汉语国际教育与研究而研制的，可以为汉语的理论研究、教学应用和信息处理工程提供语言知识资源。

《北京大学现代汉语实词句法语义功能信息词典》（简称《实词信息词典》）主要根据袁毓林教授30多年来，在认知科学的背景上，对于现代汉语的下列研究成果：（1）汉语词类的模糊划分与隶属度计算，（2）汉语配价语法研究、汉语动词与形容词的论元结构研究，（3）汉语生成词库论研究、汉语名词的物性结构研究。该词典特别重视词语之间的搭配关系和选择限制，通过大量的例子来展示目标词的意义和用法，并且提供目标词的搭配习惯和基本句型。这样做的一个理由是，正如英国语言学家J. R. Firth（1890-1960）所说：You shall know a word by the company it keeps.（欲知其词，先观其伴）Each word when used in a new context is a new word.（每一个单词出现在不同的上下文中就是一个新的单词）。的确，要了解一个词的意义和用法，最好的办法莫过于观察它跟什么样的词语搭配。并且，同一个词在不同的语境中不同程度的意义变化，也只能通过它的搭配环境来显示。这直接为汉语的国际教学提供了汉语常用实词的情境意义和搭配组合的范例，也为基于词语共现（co-occurrence）的机器学习方法，提供了一种精炼的语料库和训练样本。

《实词信息词典》分为下面三个既相对独立、又相互链接的子系统：

  1. 《汉语形容词句法语义功能信息词典暨检索系统》，收入常用形容词3千多个，4千多个义项条目；信息内容包括：词条、拼音、次类（形容词、状态词）、释义（包括：语体色彩、同义词和反义词及其链接关系等）、语义角色集合及其定义、由目标形容词和其论旨角色组配成的句法格式和相应例句、各种主要的语法功能及其词类隶属度，等等。
  2. 《汉语动词句法语义功能信息词典暨检索系统》，收入常用动词1万2千多个，1万6千来个义项条目；信息内容包括：词条、拼音、次类（8种动词小类）、释义（包括：语体色彩、同义词和反义词及其链接关系等）、语义角色集合及其定义、由目标动词和其论旨角色组配成的句法格式和相应例句、各种主要的语法功能及其词类隶属度，等等。
  3. 《汉语名词句法语义功能信息词典暨检索系统》，收入常用名词1万多个，1.2万来个义项条目；信息内容包括：词条、拼音、释义（包括：语体色彩、同义词和反义词及其链接关系等）、物性角色集合及其词例（及其跟相关动词和形容词的链接关系等）、由目标名词和其物性角色组配成的句法格式和相应例句、各种主要的语法功能及其词类隶属度，等等。

1. 汉语“把”字句自动释义和变换系统

介绍 Introduction

针对汉语“把”字句在机器翻译中的困难，“汉语‘把’字句自动释义和变换系统”将“把”字句这种具有复杂的句法语义信息的句式进行精细化的自动分析。通过规则和统计相结合的方法，对“把”字句进行自动释义和句式变换，为机器翻译等应用系统提供可供复述（paraphrase）的资料。

系统包括三个功能模块：

（1）“把”字句的自动识别：该模块实现对给定连续文本的“把”字句进行自动的框架识别。例如，对于“老干部把经验传授给新干部。”这句话的句法框架信息有：NP1=“老干部”，NP2=“经验”，NP3=“新干部”，ROOT=“传授”；语义框架信息有：A=“老干部”，P=“经验”，D=“新干部”，ROOT=“传授”。

（2）“把”字句的自动分类：该模块根据机器对已识别的框架信息的学习来对“把”字句进行分类。例如，根据框架信息和分类类别之间的对应关系（即分类模型），机器自动将这句话归入到第1类，在“把”字的标记上标为“BA1”。

（3）“把”字句的自动释义与句式变换：根据“把”字句的释义模板和句式变换模板，将框架成分代入相应的类别中。例如，释义模板是“NP1+VP+NP2，使得+NP3+获悉+NP2”，输出结果是“老干部传授经验，使得新干部获悉经验”；句式变换模板是“NP1+VP+NP2+GEI+NP3；NP2+被+NP1+VP+GEI+NP3；NP2，NP1+VP+GEI+NP3”，输出一组句式变换式：“老干部(NP1)传授(VP)经验(NP2)给(GEI)新干部(NP3)；经验(NP2)被老干部(NP1)传授(VP)给(GEI)新干部(NP3)；经验(NP2)，老干部(NP1)传授(VP)给(GEI)新干部(NP3)”。

2. 汉语“比”字句关键要素提取系统

介绍 Introduction

“比”字句是语言计算中，特别是商品评价中的重要句式，也是语言学研究的热点之一。本系统的目标是：通过对“比”字句的分析，提取“比”字句的7种关键要素（Comparative Elements）：比较主体（SUB）、比较词（BI）、比较客体（OBJ）、比较项目（ITM）、比较维度（DIM）、比较结果（RES）、比较量幅（EXT）。

系统使用两种方法提取这7种关键要素：（1）基于变换的错误驱动学习方法（TBL, Transformation-Based Error-Driven Learning）；（2）通过上下文无关文法规则，在ICGDE平台上提取。

3. 汉语语法结构测试系统

介绍 Introduction

划分汉语词类的依据是词的语法功能，而词的语法功能存在于该词所出现的句法结构之中。因此，确定词所出现的词语组合的句法结构类型是词类划分的先行工作。“汉语语法结构测试系统”以每一个具体的词语组合（两项式“X+Y”）为切入点，通过一套电子化的语法结构量表，来测量特定的词组（“X+Y”）对于相关语法结构（主谓结构、述宾结构、体词性偏正结构、谓词性偏正结构、粘合式述补结构、组合式述补结构）的隶属度。

系统以《汉语词类的认知研究和模糊划分》（袁毓林，2010）和《汉语词类划分手册》（袁毓林等，2009）为基础，将著作中的汉语语法结构量表以及相关测试过程，编制成便于人机交互的程序和界面。

4. 汉语名名组合自动释义系统

介绍 Introduction

在汉语里，定中式名名组合的内部成分之间的语义关系存在着语义压缩现象，名词和名词之间常常隐藏了谓词。例如：总统专机 → 总统[坐的]专机；摩托妈妈 → [骑/修]摩托[的]妈妈。

“汉语名名组合自动释义系统”借助名词的物性角色理论，来求解名名组合中所隐含的释义动词，从而构建出名名组合的自动释义程序。该系统对于语言教学与研究、对于自然语言处理的诸多任务（如信息检索、问答系统和机器翻译等）都有帮助。

在该系统中，名词按照《现代汉语语义词典》中名词的语义分类体系定义了语义类，并记录了名词施成角色、功用角色等物性角色信息。用户输入名名组合短语，系统将按照语义类以及其施成角色和功用角色进行自动推理，补充出隐含的谓词。

5. 汉语动词蕴涵关系查询系统

介绍 Introduction

动词之间具有蕴涵关系（entailment）是造成不同语句之间具有语义推理关系（inference）的重要因素。在自然语言中，相同的意义可以用不同的语句形式来表达，一种语句表达的意义可以从另一种语句上推断出来。例如：a. Guerrillas killed John. ——主蕴涵语句 → b. John died. ——被蕴涵语句。

在上例中，主蕴涵语句a蕴涵了被蕴涵语句b；反过来说，被蕴涵语句b的意思可以从主蕴涵语句a上推导出来。这种不同语句之间的蕴涵关系叫做文本蕴涵（textual entailment）。文本蕴涵在很大程度上是由于语句中核心动词之间具有蕴涵关系。例如：kill → die; buy → have; 告诉 → 知道；打鼾 → 睡觉；密令 → 命令。

“汉语动词蕴涵关系查询系统”提供了汉语动词蕴涵型式的录入与查询功能。随着信息的扩展，将能够为汉语词汇知识推理提供服务。

6. 汉语亲属关系自动推理系统

介绍 Introduction

亲属词语的分析和释义、亲属关系怎样来定义和推导，这是传统的词汇学和词典编纂学所关心的问题，也是现代语义学、逻辑学和计算语言学所关心的重要问题。

“汉语亲属关系推理系统”将汉语亲属词语及其所表示的亲属关系，归纳为以下七个语义特征；在亲属关系的概念领域内，它们构成语义学和逻辑学意义上的最小完备特征集合：（1）husband(x, y) x叫y丈夫；（2）child(x, y) x叫y孩子；（3）self(x, y) x叫y自己（y与x是同一个人）；（4）male(x) x为男性；（5）female(x) x为女性；（6）elder(x, y) x叫y哥/姐；（7）alone(x) x是唯一的。

通过语义特征及其相关的转换规则，实现了所有的亲属关系全覆盖，并具有数学上的先验正确性和完备性。

7. 汉语词类隶属度测试系统

介绍 Introduction

汉语词类是语法理论上的老大难问题，而汉语信息处理和对外汉语教学等应用领域，都需要可供参照的分类体系和精确的词类标注系统。“汉语词类测试系统”以每一个具体的词为切入点，通过一套电子化的词类量表，来测量特定的词对于相关词类的隶属度。

系统以《汉语词类的认知研究和模糊划分》（袁毓林，2010）和《汉语词类划分手册》（袁毓林等，2009）为基础，将著作中的汉语词类量表以及相关测试过程，编制成便于人机交互的程序和界面。
